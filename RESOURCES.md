# Structured Study Resources

Use these resources after the repository chapter, not before it. The repository gives the learning sequence and implementation; the references provide a second explanation and authoritative API details.

## How to use a resource

For each topic:

1. Read the local chapter.
2. Attempt the derivation and code from memory.
3. Use the official reference to resolve gaps.
4. Add a one-paragraph explanation in your own words.
5. Answer the interview questions without copying reference language.

Do not measure progress by videos watched. Measure it by equations reproduced, code implemented, tests passed, and explanations delivered.
